# Lib

Bundled primitives the graphs load by **name**. Not graph engineers.
A clone of this repo is enough — no pstack, Matt Pocock, or Superpowers
install required.

| Skill | Loaded by |
|---|---|
| `unslop` | all user-facing / PR text |
| `receiving-code-review` | `/lstm` verify |
| `grill-with-docs` / `grill-me` | formats + grill methodology (`GRILL.md` is the adapted loop) |
| `how` / `why` | grill, diagnose, review |
| `tdd` | implement (iron law in `TDD.md` still wins) |
| `diagnose` / `figure-it-out` | bug path |
| `architect` / `interrogate` | new module / post-spec |
| `blast-radius` | before quality |
| `to-prd` / `to-issues` | spec / tickets (local files only) |
| `typescript-best-practices` / `no-comments` | review |
| `technical-writing` | spec, PR body |
| `thermo-nuclear-code-quality-review` | quality `fix all` |

After `install.sh` they flatten next to the graphs (`/unslop`, `/how`, …).
